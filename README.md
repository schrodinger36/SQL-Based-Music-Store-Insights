# SQL-Based-Music-Store-Insights
# Music Store Data Analysis using SQL

## Project Overview
This project focuses on analyzing an online music store database using SQL to extract meaningful business insights. The analysis helps understand customer purchasing behavior, music preferences, sales performance, and revenue trends.

The project uses SQL queries to explore the database and answer business-related questions, helping transform raw data into useful insights for decision-making.

## Tools & Technologies
- **Database:** PostgreSQL
- **SQL Environment:** pgAdmin 4
- **Language:** SQL

## Database Schema
The project uses a relational Music Store database containing information about customers, employees, invoices, invoice items, tracks, albums, artists, genres, and playlists.

## Key Analysis Areas
- Identifying the best customers based on total spending.
- Analyzing countries with the highest number of customers.
- Finding the most popular music genres.
- Identifying top-performing artists based on track sales.
- Analyzing revenue generated from music purchases.
- Exploring customer purchasing patterns.
- Identifying the best-performing music tracks.

## SQL Concepts Used
- SELECT and WHERE
- ORDER BY
- GROUP BY and HAVING
- Aggregate Functions (SUM, COUNT, AVG)
- Joins (INNER JOIN, LEFT JOIN)
- Subqueries
